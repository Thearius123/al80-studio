# QMK Firmware Integration

This directory does not currently contain a full QMK source tree.

The active development firmware lives in the developer's separate QMK
workspace and is protected by known-good checkpoints.

AL80 Studio application development must not modify that QMK workspace
implicitly.

Firmware artifacts/patches intended for public distribution will be
added here deliberately after their licensing, reproducibility, and
recovery requirements are finalized.
