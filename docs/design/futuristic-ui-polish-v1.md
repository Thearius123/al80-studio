# AL80 Futuristic UI Polish V1

## Scope

This candidate combines:

1. Device Twin / Keyboard Canvas perfection
2. LCD Studio finalization / truthfulness

## Device Twin

The recovered physical key / LED map stays authoritative.

Presentation controls:

- Top
- 3D
- Fit
- 100%

Fit is the default and aims to keep the whole keyboard visible.
100% shows native canvas scale and may scroll in a smaller viewport.

The 3D transformation is visual only and never changes LED addressing.

## LCD Studio

Validated-now:

- Volume
- Mute
- typed Action feedback
- Profile / Scene typed feedback

Future protocol tracks:

- arbitrary artwork framebuffer
- GIF / timeline animation

Future capabilities remain visible as roadmap work but are not presented as
functional features.
