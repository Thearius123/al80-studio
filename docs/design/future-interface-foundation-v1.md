# AL80 Studio — Future Interface Foundation V1

Status: D1 visual foundation candidate.

## Direction

AL80 Studio uses the **Neo Instrument Lab** visual language.

The product should feel like a next-generation programmable hardware
instrument, not a conventional RGB utility.

This milestone consolidates the existing premium Creator / Display work into a
coherent shell built around:

- near-black technical depth
- restrained cyan / violet energy
- glass instrument surfaces
- clear live/safe semantic states
- monospace telemetry accents
- subtle grid and signal motifs
- motion that communicates state rather than decorating idle screens

## What D1 changes

D1 is visual only.

It strengthens:

- application environment
- navigation rail
- page hierarchy
- panels
- controls
- status badges
- Creator workflow
- Digital Twin presentation
- Effect Lab cards
- Input/Profile surfaces
- Display Studio
