# AL80 Studio Roadmap

## v0.1.0-alpha

Goal: establish a safe desktop control plane.

- detect AL80
- open Raw HID
- display connection state
- query matrix scan rate
- query/toggle RGB runtime state
- query/toggle custom overlay state
- send volume/mute state
- Linux audio event integration
- diagnostics page
- no automatic firmware flashing

## v0.2

- RGB configuration UI
- color controls
- speed controls
- presets
- profile import/export

## v0.3

- LCD visual editor
- text widgets
- volume widget
- battery widget
- clock/system widgets
- safe preview pipeline

## v0.4

- key remapping
- macros
- profile switching
- firmware compatibility detection
- guarded firmware updater

## v1.0

- stable Linux release
- packaged application
- documented protocol
- reproducible firmware builds
- recovery workflow
